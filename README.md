# WLPA Species Search

Live at https://wlpa-species-search.streamlit.app/

Search the species in Schedules I–IV of the Wild Life (Protection) Act, 1972,
**as on 5 June 2025** (India Code consolidation), with CITES and IUCN status.

- `WLPA_species_reference.html` is the whole app: one self-contained page,
  also usable offline by opening it in a browser. It is generated by the
  `wlpa-db` project (`python rebuild.py`); do not edit it here.
- `WLPA-App.py` (and `app.py`, the same file) shows that page on Streamlit.
- `legacy/` is the earlier Excel-based app (2025), kept for reference.

To update: copy the newly built `dashboard/WLPA_species_reference.html` from
`wlpa-db` over the one here, commit and push.
